# Где лежит

Простой трекер "что где лежит" с синхронизацией между устройствами через приватный GitHub Gist.

## Настройка после деплоя

1. Открыть страницу (URL см. ниже, зависит от способа деплоя).
2. Нажать на статус в правом верхнем углу ("не подключено").
3. Создать токен: https://github.com/settings/tokens → scope `gist` (ссылка есть прямо в окне настроек приложения).
4. Вставить токен, поле Gist ID оставить пустым → "Подключить". Приложение создаст приватный gist и покажет его ID.
5. На втором устройстве (телефон) открыть тот же URL → в настройках вставить **тот же токен** и **тот же Gist ID** → "Подключить".

Токен и Gist ID хранятся только в localStorage браузера устройства, никуда в код не попадают.
