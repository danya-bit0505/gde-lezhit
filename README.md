# Где лежит

Трекер «что где лежит». Работает офлайн, синхронизируется двумя способами: через приватный GitHub Gist и напрямую между устройствами по QR (без интернета).

## Файлы в репозитории (все в одной папке)

    index.html  sw.js  qrcode.js  manifest.json
    icon-192.png  icon-512.png  apple-touch-icon.png
    favicon-16.png  favicon-32.png  favicon.ico  .nojekyll

Необязательно: `jsQR.js` (из npm-пакета `jsqr`, файл `dist/jsQR.js`) — нужен для сканирования QR на iPhone, в Safari и Firefox. В Chrome на Android работает и без него.

## Обмен по QR

1. Оба устройства в одной Wi-Fi сети (интернет не нужен) или на одном из них включена точка доступа.
2. Кнопка ⇄ в шапке. Первое устройство: «Показать код». Второе: «Сканировать код».
3. Знакомое устройство подключается сразу, и на первом появляется вопрос «Принять / Отклонить».
4. С новым устройством первый раз нужны два сканирования: второе покажет ответный код, на первом нажмите «Далее» и наведите камеру. После этого устройства запоминают друг друга.

Каждое устройство хранит постоянный ключ (в IndexedDB, срок — год) и отпечатки знакомых устройств. Список знакомых и «Забыть» — в настройках. Если браузер не умеет быстрый путь, обмен сам переходит на два сканирования.
Если камеры нет или она не читает, код можно скопировать текстом и вставить вручную.

## Резервная копия

Настройки → «Резервная копия»: файл `gde-lezhit-ГГГГ-ММ-ДД.json` со всеми вещами (без токена Gist), работает без интернета. «Загрузить из копии» не заменяет список, а сливается с ним. Автоматически — раз в N дней (по умолчанию 7, 0 — выключено): копия сохраняется в «Загрузки» при первом касании экрана после срока. На старых айфонах — напоминание и копия текстом.

## Gist

Статус в шапке → токен (scope gist) и ID gist'а. Подробности в окне настроек.

## Как работает слияние

Удаление хранится как «надгробие» (запись с `deleted: true`), поэтому удалённая вещь не воскресает при синхронизации. Если вещь удалили на другом устройстве, приложение спрашивает: удалить у себя или оставить. Побеждает более свежая правка; вещи подписаны владельцем (`owner`).

Обновлять приложение нужно на всех устройствах до того, как они начнут синхронизироваться между собой: старая версия не знает про надгробия.
